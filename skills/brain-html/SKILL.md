# Brain HTML

원본 `command-center`의 다섯 시각화 엔진과 테마·모션을 재사용한다. 단순한 분위기 설명이나 정적인 그래프 그림으로 끝내지 말고 실제 노드 탐색, 포커스, 필터, 레이어, 회전이 작동하는 결과를 만든다. 이 전역 스킬 안에 다섯 **스타일 모드**가 있다.

## 처음에는 선택지를 보여준다

스킬을 호출하면 아래 보기를 사용자에게 짧게 보여준다. 이미 모드를 지정했다면 그 선택을 적용하고 나머지는 선택 가능하다고만 안내한다.

| 보기 | 그래프·모션 | 적합한 요청 |
|---|---|---|
| **자동 선택** | 내용에 맞는 주 스타일 + 필요한 보조 그래프 | 스타일을 지정하지 않았을 때 |
| **1 · Brain** | 동심원 노드, 중앙 지식 코어, 포커스 전환, 신경망 | 개념 관계, 시스템 구조, 프로젝트·지식 탐색 |
| **2 · Doctor** | 다층 레이더, 진단 코어, 미터, 계단형 추이 | 상태 점검, 역량·성과 비교, 커버리지 |
| **3 · Funnel** | 단계별 이동 궤도, 흐름/방사형 전환, 개별 노드 정보 | 고객 여정, 전환, 진행 단계, 파이프라인 |
| **4 · AdPilot** | 관성 회전 지구본, 도시 핀, 붉은 광원, 성과 매트릭스 | 지역·글로벌 분포, 광고 캠페인, 도달 범위 |
| **5 · Personas** | 역할별 조직도, 페르소나 전환, 색상별 지식망 | 팀·역할·사용자 유형, 운영체계 비교 |

- 비동기 선택 도구가 있으면 **선택은 선택사항**임을 밝히고 `자동 선택`, 위 다섯 이름을 보기로 제공한다. 자료 분석·데이터 구성은 계속한다. 응답이 없으면 멈추거나 반복 질문하지 말고 요청에 맞게 진행한다. 선택할 합리적인 기회는 준다.
- 도구가 없으면 위 표와 “선택을 생략하면 [추천 모드]로 진행합니다”를 보여준 뒤 계속한다.
- 사용자가 “알아서”, “자동”이라고 했으면 질문하지 않고 추천 모드와 이유를 한 문장으로 알린다.
- **주제 자체가 없는 `$brain-html` 호출**은 샘플 데이터임을 표시한 스타일 갤러리를 열거나 링크한다. 임의 사업 주제로 완성품을 만들지 않는다.
- 실제 움직이는 선택 갤러리: [다섯 스타일 보기](assets/examples/style-gallery.html). 이 HTML은 모든 코드와 지구본 데이터를 포함하며 로컬 파일로도 열린다. 필요하면 해당 폴더만 loopback HTTP로 제공한다.
- 모양을 먼저 비교할 때는 [다섯 화면 미리보기](references/previews.md)를 보여준다. 선택한 모드의 이미지 한 장만 읽어도 시각 기준을 확인할 수 있다.
- Codex 네이티브 스킬 목록에는 `agents/openai.yaml`의 이름·설명이 표시된다. 위 선택 안내는 스킬을 **호출한 후**의 대화 동작이다. 네이티브 선택기에 커스텀 버튼을 설치했다고 주장하지 않는다.

## 자동 선택과 조합

요청에서 사용자가 알아내려는 것을 기준으로 선택한다. 관계/연결은 Brain, 여러 축의 상태/비교는 Doctor, 순차 진행/전환은 Funnel, 실제 지리 좌표는 AdPilot, 역할별 구성 비교는 Personas다. `/brain처럼` 또는 스타일만 요청하면 Brain을 기본으로 한다.

하나의 주 시각화를 크게 배치한다. 필요할 때만 보조 모드를 추가한다. 예: “AI 팀 구조와 건강도” → Brain + Doctor, “해외 고객의 유입과 전환” → AdPilot + Funnel, “직군별 AI 조직 설계” → Personas. 모든 요청에 다섯 개를 억지로 넣지 않는다. 지리 정보가 없는데 지구본에 가짜 도시를 만들지 않는다.

## 제작

1. [디자인·모션 규칙](references/design-system.md)을 읽고 선택한 모드의 [엔진 안내](references/engines.md) 부분을 읽는다. 원본 접근이 불가능해도 이 스킬의 소스와 갤러리로 진행할 수 있다.
2. 요청 내용을 데이터 모델에 맞춘다. [데이터 계약](references/data-contract.md)을 읽는다. 사용자 데이터와 샘플 숫자를 섞지 않는다. 빈 배열/미측정 상태를 유지한다.
3. 독립 HTML이면 내장 생성기로 시작한다. 런타임은 미리 빌드되어 Python 표준 라이브러리만 필요하다. 아래 `SKILL_ROOT`는 **현재 읽은 스킬 폴더의 실제 절대 경로**로 정한다.

```bash
python3 "$SKILL_ROOT/scripts/render.py" --mode brain --data content.json --output output/index.html
python3 "$SKILL_ROOT/scripts/render.py" --mode brain --sections doctor --data content.json --output output/overview.html
python3 "$SKILL_ROOT/scripts/render.py" --showcase --output output/styles.html
```

`--data`가 없으면 명시적으로 표시한 샘플이다. `--data`를 주면 샘플을 자동으로 합치지 않는다. `--sample`은 사용자가 샘플 시연을 원할 때만 쓴다. `--theme mono|dark|midnight|ember|mono-light`, `--title`을 지원한다. 기존 출력 파일은 덮어쓰지 않는다.

4. 생성 결과는 출발점이다. 사용자 주제의 제목·노드·설명·지표를 실제로 반영하고, 요구가 프리셋보다 크면 `assets/runtime/`를 **작업 폴더로 복사해서** 수정한다. 글로벌 스킬 원본을 개별 결과물 때문에 수정하지 않는다. [소스 재사용·빌드](references/reuse.md)를 따른다.
5. React/Next 앱에 통합하는 요청이면 필요한 엔진·순수 레이아웃 모듈·CSS를 선별한다. 원본 `app/*/page.tsx`는 서버 결합 구조를 설명하는 참고용이다. 데이터베이스·외부 커넥터를 복제하지 않는다.
6. 결과를 브라우저에서 열어 선택 모드의 핵심 상호작용, 좁은 화면, 콘솔 오류, 감소된 모션을 확인한다. 새 데이터를 썼다면 노드 연결과 수치도 대조한다. 빌드 통과만으로 시각 검증 완료라고 하지 않는다.

## 보존할 기준

- `/brain`의 충실한 재현은 `KnowledgeGraph` + `BrainGraphView` + `tree-layout` + `memory-core`를 사용한다. 가벼운 `PersonaBrainGraph`를 대신 넣어 같은 엔진이라고 하지 않는다.
- **펼친 트리는 마지막 기술 노드까지 화면 안에 유지한다.** 노드를 선택할 때 고정 비율로 다시 확대하지 않는다. 실제 노드·코어의 범위와 표시 중인 SVG 크기로 화면을 맞추고 상단 제목·하단 버튼의 여백을 확보한다. 전체 화면 포털의 지연 마운트와 크기 변경에도 관찰자를 다시 연결한다. [트리 화면 맞춤 규칙과 회귀 검증](references/tree-framing.md)을 따른다.
- 원본 기본값은 검정 Monolith다. 파티클 코어, 얇은 연결선, 동심원 티어, 제어된 색상, 실제 포커스 전환이 우선이다. 형광 그라디언트 카드나 범용 차트로 대체하지 않는다.
- 폰트는 mono 계열, 표면/테두리/숫자 위계와 원본 타이밍은 공통이다. 테마는 토큰으로 바꾸고 AdPilot의 붉은 테마는 페이지 안에 한정한다.
- CSS, SVG, RAF 모션 모두 `prefers-reduced-motion`을 존중한다. 노드가 바뀌면 이름 있는 버튼/목록으로도 탐색할 수 있게 유지한다. Canvas 지구본에는 텍스트 지역 요약을 제공한다.
- 외부 API 실행, 광고 집행, 에이전트 실행, 문서 저장을 시각 스타일 추출에 끼워 넣지 않는다. 내장 독립 어댑터는 네트워크를 호출하지 않는다. 연결이 필요하면 별도의 명시적 앱 요구로 구현한다.
- [출처 해시](references/source-manifest.json)와 `assets/licenses/`의 MIT 고지를 보존한다. 원본 소스·독립 어댑터·샘플 데이터·검증한 상태를 구분한다.

## 완료 보고

생성한 HTML/앱 위치, 선택한 스타일과 이유, 작동을 확인한 핵심 상호작용만 간결하게 알린다. 샘플 데이터나 미검증 항목이 있으면 명확히 적는다.
